موقع فهد مبارك — إصدار إصلاح المزامنة V3

ما تم إصلاحه في هذا الإصدار:
- تفعيل Supabase Realtime على جداول الموقع الأساسية حتى تصل تغييرات الأجهزة الأخرى تلقائيًا.
- إضافة إعادة جلب آمنة عند عودة الاتصال أو الرجوع إلى التبويب.
- إصلاح رفع المحتوى المحلي غير المزامن إلى قاعدة البيانات بدل اعتباره محفوظًا مسبقًا.
- مزامنة مجتمع الأعضاء والردود عبر جداول سحابية مع صلاحيات لكل مستخدم.
- مزامنة نبذة وصورة الملف الشخصي عبر Supabase Storage وprofiles.
- تمكين إرسال الإشعارات للأعضاء المسجلين.
- إضافة مؤشر حالة المزامنة وزر «مزامنة الآن» في لوحة الإدارة.
- تحديث واجهة دعوة الأعضاء لتوضيح أن التفعيل يتم عبر البريد.

الملفات:
- index.html
- supabase-auth.js
- supabase-data.js
- _redirects
- robots.txt

النشر على الموقع الحالي:
1) فك ضغط هذا الملف.
2) افتح Netlify ثم مشروع fahad-mubarak ثم Deploys.
3) اسحب محتويات المجلد كاملة إلى منطقة الرفع، وتأكد أن index.html في جذر الملفات وليس داخل مجلد فرعي.
4) انتظر حتى تصبح حالة النشر Published/Ready.
5) افتح https://fahad-mubarak.netlify.app وسجّل الدخول من جديد إذا طلب منك ذلك.

مهم:
- تغييرات قاعدة البيانات وسياسات RLS وRealtime طُبّقت بالفعل على مشروع Supabase المرتبط.
- لا تنشئ مشروع Supabase جديدًا ولا موقع Netlify جديدًا.
- لا تحذف بيانات المتصفح ولا تمسح بيانات الموقع قبل التأكد من ظهور محتواك بعد النشر.
- ملفات الواجهة لا تحتوي على service-role key أو كلمات مرور.
- المزامنة الفورية تحتاج اتصال إنترنت؛ عند انقطاعه يعيد الموقع جلب البيانات عند عودة الاتصال.
